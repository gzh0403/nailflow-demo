# NailFlow P2 可视化交互原型

**这是一份公开演示样品（public demonstration sample），使用虚构数据，不是商业产品（not a commercial product）。** 页面里的门店、顾客、订单与金额均为演示虚构内容，不代表真实经营，也不提供真实支付或顾客服务。

在线演示（GitHub Pages）：https://gzh0403.github.io/nailflow-demo/

这是美甲美睫门店产品 **NailFlow** 的 P2 静态浏览器原型，供查看视觉与交互。无需构建、无需安装依赖、没有后端。

## 如何打开

1. 打开在线演示：https://gzh0403.github.io/nailflow-demo/
2. 或用浏览器直接打开本目录里的 `index.html`（无需安装、无需构建）。
3. 也可以在本目录执行：

```bash
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

建议使用 Chrome、Edge 或 Safari 较新版本。首次打开会写入浏览器本地存储；页面顶部有「一键重置演示数据」。

更完整的页面导航、建议体验顺序和品牌说明，请看同目录的《体验与导航说明.md》。已实现与缓停范围见《已实现与尚未实现清单.md》。
